
Работа с данными предметов:

1. items_reader.py - Чтение данных предметов
   - Читает данные из items.txt
   - Связывает с иконками
   - Подготавливает к анализу

2. items_data.json - Файл с данными предметов
   - Содержит данные предметов
   - Связывает с иконками
   - Используется для анализа

3. item_data_processor.py - Обработка данных предметов
   - Обрабатывает данные предметов
   - Связывает с иконками
   - Подготавливает к анализу

4. item_analysis.py - Анализ данных предметов
   - Анализирует данные предметов
   - Связывает с иконками
   - Обеспечивает точность анализа

5. items_data.json - Файл с данными предметов
   - Содержит данные предметов
   - Связывает с иконками
   - Используется для анализа

Ключевые особенности:
- Все скрипты работают с предметами как основным источником данных
- Используют данные из items.txt для данных предметов
- Связывают данные предметов с иконками и ценами
- Обеспечивают согласованность данных

Рекомендации:
- Проверьте соответствие данных предметов с иконками
- Используйте items_reader.py для чтения данных
- Обновляйте данные предметов при изменении данных
- Проверяйте корректность анализа через item_analysis.py

Для запуска:
python items_reader.py
python item_data_processor.py
python item_analysis.py
