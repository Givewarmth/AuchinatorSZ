
Скрипты для обработки скриншотов и сравнения с иконками:

1. check_screenshot.py - Основной скрипт для проверки скриншотов
2. screenshot_processor.py - Обработка скриншотов для анализа
3. screenshot_icon_comparator.py - Сравнение скриншотов с иконками
4. compare_images.py - Сравнение изображений
5. image_comparison.py - Более точное сравнение изображений
6. find_icons.py - Поиск иконок на скриншотах
7. find_matches.py - Поиск совпадений иконок
8. find_all_matches.py - Поиск всех совпадений
9. analyze_icons.py - Анализ иконок
10. icon_price_mapper.py - Сопоставление иконок с ценами

Система работы:
- Иконки загружаются из папки icons
- Скриншоты из папки screenshots
- Используется файл mapping.json для сопоставления иконок с ценами
- Для аукциона используется vendor_data.txt с ценами
- Названия предметов берутся из sandbox/data/items

Рекомендации:
- Проверьте vendor_data.txt для получения цен
- Используйте items.txt для получения названий предметов
- Используйте mapping.json для сопоставления иконок с ценами
