
Работа с данными предметов:

1. items.txt - Основной файл данных предметов
   - Содержит информацию о предметах
   - Связывает с названиями и иконками
   - Используется для крафта и аукциона

2. items_reader.py - Чтение данных предметов
   - Загружает данные из items.txt
   - Обрабатывает структуру данных
   - Подготавливает к использованию

3. item_data_processor.py - Обработка данных предметов
   - Преобразует данные предметов
   - Связывает с иконками
   - Подготавливает к анализу

4. item_analysis.py - Анализ данных предметов
   - Основной модуль анализа
   - Сравнивает с данными иконок
   - Оценивает соответствие

5. items_data.json - Файл данных предметов в формате JSON
   - Содержит структурированные данные
   - Используется для крафта и аукциона
   - Связывает с иконками и ценами

Ключевые особенности:
- Все скрипты работают с items.txt как основным источником данных
- Используют данные из sandbox/data/items для названий предметов
- Связывают цены с иконками и предметами
- Обеспечивают согласованность данных

Рекомендации:
- Проверьте соответствие данных с иконками
- Используйте items_reader.py для загрузки данных
- Обновляйте items.txt при изменении данных
- Проверяйте корректность анализа через item_analysis.py

Для запуска:
python items_reader.py
python item_data_processor.py
python item_analysis.py
