
Программа анализа данных поставщика

Основные компоненты:
1. vendor_data.txt - файл с ценами на предметы от поставщика
2. mapping.json - файл сопоставления предметов и иконок
3. items.txt - файл с описаниями предметов

Функции программы:
- Загрузка данных из файлов
- Сравнение цен с базовой ценой крафта
- Определение выгодности покупки/крафта
- Вывод информации о предметах с иконками и описаниями

Результаты анализа:
- Для каждого предмета показывается цена
- Определяется, выгоднее купить или крафтить
- Показывается разница в ценах
- Отображается описание предмета

Примеры использования:
- Сравнение цен на предметы
- Определение оптимальных стратегий крафта
- Анализ данных для аукциона

Программа готова к использованию!
