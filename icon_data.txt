
Работа с данными иконок:

1. icons/ - Папка с иконками
   - Содержит все иконки предметов
   - Связано с данными из items.txt

2. icon_data_handler.py - Обработчик данных иконок
   - Обрабатывает данные иконок
   - Связывает с предметами
   - Подготавливает к анализу

3. icon_matches.txt - Файл с матчами иконок
   - Содержит сопоставления иконок с предметами
   - Связано с данными из items.txt

4. icon_price_mapper.py - Сопоставление иконок с ценами
   - Сопоставляет иконки с ценами
   - Использует mapping.json
   - Связано с данными из items.txt

5. icon_price_mapping.py - Сопоставление иконок с ценами
   - Сопоставляет иконки с ценами
   - Использует mapping.json
   - Связано с данными из items.txt

Ключевые особенности:
- Все скрипты работают с иконками из папки icons/
- Связаны с данными из items.txt
- Обеспечивают точное сопоставление иконок с предметами
- Связывают данные иконок с ценами

Рекомендации:
- Проверьте соответствие иконок предметам
- Используйте icon_data_handler.py для обработки
- Обновляйте данные сопоставления при изменении данных
- Проверяйте корректность сопоставления через icon_price_mapper.py

Для запуска:
python icon_data_handler.py
python icon_price_mapper.py
python icon_price_mapping.py
