
Анализ скриншотов и иконок:

1. check_screenshot.py - Основной скрипт проверки скриншотов
   - Проверяет скриншоты на наличие иконок
   - Сравнивает с эталонными иконками
   - Создает отчет о совпадениях

2. screenshot_processor.py - Обработка скриншотов
   - Подготовка скриншотов к анализу
   - Преобразование форматов
   - Подгонка размеров

3. screenshot_icon_comparator.py - Сравнение скриншотов с иконками
   - Основной модуль сравнения
   - Использует алгоритмы сравнения
   - Создает отчет о совпадениях

4. compare_images.py - Сравнение изображений
   - Базовый алгоритм сравнения
   - Работа с пиксельными данными
   - Оценка схожести

5. image_comparison.py - Расширенное сравнение изображений
   - Более точные алгоритмы
   - Работа с цветовыми паттернами
   - Сравнение с эталонами

6. find_icons.py - Поиск иконок
   - Поиск иконок на скриншотах
   - Работа с цветами и формами
   - Определение совпадений

7. find_matches.py - Поиск совпадений
   - Поиск всех совпадений
   - Сравнение с эталонами
   - Создание отчета

8. analyze_icons.py - Анализ иконок
   - Подробный анализ иконок
   - Сравнение с базой данных
   - Оценка соответствия

9. final_analysis.py - Финальный анализ
   - Комплексный анализ
   - Сводка всех данных
   - Создание финального отчета

Ключевые особенности:
- Все скрипты используют систему сравнения для определения соответствия
- Использует файлы из папки screenshots и icons
- Работает с данными из mapping.json и vendor_data.txt
- Использует данные из items.txt для названий предметов

Рекомендации:
- Проверьте соответствие скриншотов иконкам
- Используйте compare_images.py для точного сравнения
- Анализируйте данные через find_icons.py и find_matches.py
- Создавайте отчеты через final_analysis.py

Для запуска:
python check_screenshot.py
python screenshot_processor.py
python screenshot_icon_comparator.py
python compare_images.py
python image_comparison.py
python find_icons.py
python find_matches.py
python analyze_icons.py
python final_analysis.py
