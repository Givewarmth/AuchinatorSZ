
Система крафта и аукциона:

1. crafting_calculator.py - Калькулятор крафта
   - Рассчитывает выгоду от крафта
   - Использует данные из vendor_data.txt
   - Сравнивает стоимость материалов с продажной ценой

2. vendor_optimizer.py - Оптимизация данных вендора
   - Анализирует данные из vendor_data.txt
   - Оптимизирует цены для аукциона
   - Создает отчеты по выгоде

3. vendor_price_analysis.py - Анализ цен вендора
   - Сравнивает цены на предметы
   - Анализирует прибыльность
   - Создает отчеты

4. compute-craft-profit.js - JavaScript для расчета выгоды крафта
   - Асинхронный расчет
   - Использует данные из vendor_data.txt

5. final_vendor_analysis.py - Финальный анализ данных вендора
   - Комплексный анализ
   - Сравнение с предыдущими данными
   - Создание финального отчета

6. vendor_analysis_final.py - Финальный анализ вендора
   - Комбинирует все данные
   - Создает сводный отчет

Ключевые особенности:
- Вендор всего один, поэтому данные из vendor_data.txt являются основными
- Система использует ценовые данные для анализа выгоды
- Использует информацию из items.txt для названий предметов
- Сопоставление иконок с ценами через mapping.json

Рекомендации:
- Проверьте vendor_data.txt на актуальность цен
- Используйте crafting_calculator.py для расчета выгоды крафта
- Анализируйте данные через vendor_optimizer.py
- Проверьте отчеты по прибыльности через vendor_price_analysis.py

Для запуска:
python crafting_calculator.py
python vendor_optimizer.py
python vendor_price_analysis.py
python final_vendor_analysis.py
