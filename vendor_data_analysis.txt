
Работа с данными vendor и предметами:

1. vendor_data.txt - Основной файл данных vendor
   - Содержит 6 строк цен для предметов
   - Связывает предметы с ценами
   - Используется для крафта и аукциона

2. vendor_data_reader.py - Чтение данных vendor
   - Загружает данные из vendor_data.txt
   - Обрабатывает структуру данных
   - Подготавливает к использованию

3. vendor_analysis.py - Анализ данных vendor
   - Основной модуль анализа
   - Сравнивает с данными иконок
   - Оценивает соответствие

4. vendor_analysis_final.py - Финальный анализ vendor
   - Комплексный анализ данных
   - Сводка всех данных
   - Создание финального отчета

5. vendor_analysis_improved.py - Улучшенный анализ vendor
   - Более точные алгоритмы
   - Работа с дополнительными источниками
   - Обеспечивает точность анализа

6. vendor_optimizer.py - Оптимизация данных vendor
   - Улучшает эффективность
   - Повышает точность
   - Обеспечивает согласованность

7. vendor_price_analysis.py - Анализ цен vendor
   - Подробный анализ цен
   - Сравнение с эталонами
   - Оценка соответствия

8. create_vendor_data.py - Создание данных vendor
   - Генерирует vendor_data.txt
   - Связывает с ценами
   - Обеспечивает правильную структуру

9. vendor_data_new.txt - Новые данные vendor
   - Обновленная версия данных
   - Содержит улучшенную информацию
   - Используется для крафта

10. vendor_data_reader.py - Ридер данных vendor
    - Загружает данные из vendor_data.txt
    - Обрабатывает структуру данных
    - Подготавливает к использованию

Ключевые особенности:
- Все скрипты работают с vendor_data.txt как основным источником данных
- Используют данные из items.txt для названий предметов
- Связывают цены с иконками и предметами
- Обеспечивают согласованность данных

Рекомендации:
- Проверьте соответствие данных с иконками
- Используйте vendor_data_reader.py для загрузки данных
- Обновляйте vendor_data.txt при изменении цен
- Проверяйте корректность анализа через vendor_analysis.py

Для запуска:
python vendor_data_reader.py
python vendor_analysis.py
python vendor_analysis_final.py
python vendor_analysis_improved.py
python vendor_optimizer.py
python vendor_price_analysis.py
python create_vendor_data.py
