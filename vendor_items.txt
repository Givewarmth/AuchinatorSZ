
Работа с данными vendor и предметами:

1. vendor_data.txt - Данные vendor
   - Содержит 6 строк с ценами
   - Связано с данными из items.txt
   - Содержит информацию о предметах

2. items.txt - Данные предметов
   - Содержит данные о предметах
   - Связано с данными из sandbox/data/items/
   - Содержит названия предметов

3. vendor_data_reader.py - Чтение данных vendor
   - Читает данные из vendor_data.txt
   - Связано с данными из items.txt
   - Подготавливает данные для анализа

4. vendor_analysis.py - Анализ данных vendor
   - Анализирует данные vendor
   - Связано с данными из vendor_data.txt
   - Подготавливает данные для анализа

5. items_reader.py - Чтение данных предметов
   - Читает данные из items.txt
   - Связано с данными из sandbox/data/items/
   - Подготавливает данные для анализа

Ключевые особенности:
- Все скрипты работают с данными из vendor_data.txt
- Связаны с данными из items.txt
- Обеспечивают точный анализ данных vendor
- Связывают данные vendor с данными предметов

Рекомендации:
- Проверьте соответствие данных vendor и предметов
- Используйте vendor_data_reader.py для чтения данных
- Обновляйте данные vendor при изменении предметов
- Проверяйте корректность анализа через vendor_analysis.py

Для запуска:
python vendor_data_reader.py
python vendor_analysis.py
python items_reader.py
